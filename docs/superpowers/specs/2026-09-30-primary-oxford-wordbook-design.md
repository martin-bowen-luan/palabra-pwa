## 3. 方案选择

采用“一份英语词典 + 多份词书目录 + 一份英语记忆”。保留全部旧英语词条 ID；804 个重合词的目录直接指向已有 ID，新增 243 个词形使用相同的 `en:<normalized-term>` 命名规则。学习记录仍以该词的 ID 为键，不在词书里复制。

现有高考资料不被小学抓取记录盲目覆盖：同词有效资料按规范化义项、例句去重合并，保留来源。小学目录可配置优先展示的常用义项、例句及大小写，不改变词的学习 ID；两个词书读到的都是公共词典中的资料，而非各自重建完整词条。资料冲突进入审核报告，不自动以后导入内容覆盖。

首版词表 ID 为 `en-highschool`、`en-oxford-primary`、`es-foundation`。小学不同年级/学期只作为同一本词表的归属筛选，不额外拆成十二套进度。

## 4. 使用体验与默认规则

- 英语主页面增加文字式词表选择：高考 3500 / 小学必背单词（牛津版）。首次升级维持用户原有语言，英语默认仍选高考，不自动切换或开始新任务。
- 今日、词库、进度、设置明确显示当前词表。小学词库提供年级“全部、一至六年级”、学期“全部、上、下”筛选；组合条件作用于同一册归属，不能将不同归属交叉匹配。
- 今日页可选择小学新词的年级与学期范围，默认全部；与词库浏览筛选分开保存，浏览搜索不暗中改变学习计划。范围内新词按年级、上/下学期排序，同一册沿用源文件出现顺序；源文件不含课内单元顺序，不宣称按课文顺序。
- 年级范围只限定新词。到期复习仍覆盖小学词表所有已学词，并以文字说明，避免换年级后遗漏复习。小学词表内同词多册不重复学习或计数。
- 英语日目标、已练习数量、统计和连续学习天数统一累计，不因换书额外增加每日额度。同词在任一本书被标熟练后，其他书立即同步；同词只有一个到期日期，不形成两个复习任务。
- 今日页默认学习当前书的新词，复习显示当前书到期数量；另列“全部英语待复习”入口，防止换书后遗忘书外到期词。各词书完成度由成员 ID 对共享进度计算，不能把两书完成词数直接相加当作英语总数。
- 学习页不提供词书切换。首页、词库可切换并记住选择；全英语只保留一组未完成会话，记录其来源书与范围，避免同词同时进入两组。退出后可浏览另一词书，但开始学习前提示“继续上次的高考/小学学习”；完成该组后才按当前选择开新组。不丢弃未完成内容来切书。
- 清空记录明确为“清空全部英语学习记录”，提示“高考与小学共用记忆，都会重置”，必须确认。不提供容易误解的“只清空这本书”按钮；不影响西语、词典、AI 配置或 Wordle。
- 继续使用练习纸与蓝色批注，不新增底部导航或卡片仪表盘；筛选与选择控件有键盘焦点、44px 触控区及深色样式。

## 5. 词典整理与内容质量

新增可重复执行的导入器，读取该 JSON，校验数量、版本、唯一词形及有效册归属。只提取词形、词性、中文义项、英中例句、发音信息、特殊变形、相关词、来源 URL、抓取时间和年级学期归属。输出轻量词库 JSON、册目录和质量报告；网页 HTML 不进入产物或运行时。

保留原始显示大小写；规范化 ID 使用 Unicode NFC、首尾去空白、统一单词间空格及小写。不将连字符、撇号或词形变体随意折叠为同一 ID。短语保留为完整学习单位，拼写提示不把空格和标点作为需要揭示的字母。

词性由明确的词性标记解析，不使用“第一个汉字之前都算词性”的规则，避免吞掉 `X光` 的 X、括号内学科标签等正文。来源 `detail_url` 正确映射为词典链接。多义项保留词性关联，不能把后一义项的词性误并入第一义项。

4 条缺失释义以小学常用义补齐并记录补充来源；疑似错义或不适龄义项列入报告并逐项处理。8 条缺失例句在开发阶段补充自然、简短的情境句和中文译文，逐条复核；允许编辑原创句，明确标记为编辑补充，不伪称来自抓取网站。不调用用户密钥或付费生成服务，也不在学习时临时生成题目。

对已有例句检查英中配对、空值、用法标题混入、残句、乱码、占位表达和目标词/正确变化形式是否出现；机器报告中的问题逐条人工复核，不能用“有字符串”代替有效例句。不无条件复制高考词表的资料，例如现有 `seaweed` 例句残缺，不能用来补齐小学内容。

短语可在自然例句中用合理变形，例如 `on one's way to` 可对应 `on my way to school`；记录匹配或编辑审核说明，不因缺少逐字子串误删有效例句。拼写答案仍为当前词条完整词形，原有忽略大小写和首尾空格规则不变；常见拼写变体只在核验后显式配置。

学习卡最多展示 3 个常用中文义项与 1 组例句，详情最多 3 组；完整源记录不等于全部显示。所有小学学习单位至少一条合格双语例句和非空中文义项，未解决缺口阻止正式构建收录，不能静默丢词后声称 1,047 条齐全。

## 9. 手机学习界面与键盘问题

### 调查证据与待验证部分

现有 `.studyPage`、外层、body/root 多处使用 `min-height: 100vh`，学习头部处于普通文档流，西语按钮纵向堆叠；英语也存在 30–48px 的固定纵向空白。未找到 visualViewport 适配。西语切题和插入重音字母会调用没有 `preventScroll` 的 `focus()`。

本轮在本地当前代码、390×844 浏览器视口检查西语首题：检查按钮 y=571–625，底部跳过 y=703–749。将视口缩至 390×440 后，内容高度仍约 773px；整页滚动 333px 后，头部位于 y=-333 至 -269，完全不可见。由此确认小可见高度下内容不会收紧，整页滚动会丢失顶部操作。

这不是 iPhone 真键盘复现：真实软键盘可能仅改变 visual viewport，不改变 layout viewport。自动聚焦对 Safari 的具体滚动影响尚需真机记录，不能宣称已验证。实现先加入可见高度、偏移、聚焦和按钮边界的针对性测试，再验证每项调整，不能仅换成 `100dvh` 就宣布解决。

### 视觉与布局方案

沿用现有明确的蓝铅笔视觉，而非另换装饰风格：练习纸 `#F5F6F2`、墨黑 `#172128`、蓝 `#3157C8`、线 `#D8DDE1`、绿 `#247461`、红 `#B84C49`；深色继续使用现有变量。西文 Source Serif 4，中文 Noto Sans SC。

中文提示保持主层级，常态约 24–28px，小高度约 20–24px；西文词形常态约 44–60px，小高度约 32–40px，句子约 20–26px；语法标签 12–13px，保留阴阳性颜色和文字。输入文字不低于 16px，常规正文不靠极小字号压缩。

学习界面分三段，正文与操作共用左对齐，词形与中文意义仍是视觉重点：

```text
结束              进度        熟练  ← 始终可达
───────────────────────────────
中文提示 / 词形 / 小号语法标签
题目、例句与反馈                    ← 仅此区必要时滚动
───────────────────────────────
输入框 / 西语重音字母
提示字母       不认识        跳过
检查答案 / 继续                     ← 键盘上方
系统键盘
```

正常手机竖屏、普通长度题目尽量一屏；长句、错误比较、AI 内容和大字体允许中间区域滚动，固定区不能遮住最后一行或焦点。极端矮屏或放大时允许更保守的可访问布局，不能裁剪内容或拦截用户缩放。

英语四关进度压缩为一行，只保留一个当前关卡说明，去掉重复标题与大空白。次级操作同排或两列排布，各按钮仍至少 44px。词根/派生/AI 长资料默认折叠到“词汇详情”，用户展开后可滚动，不让答题按钮被长资料推到页面底部。

键盘开启时优先保留目标中文、必要题干、输入、提交及退出。例句译文等辅助内容可收起但有明确展开入口；不提前显示测试答案。首次进入题目不强行弹出键盘，用户点输入框后进入紧凑状态；已在连续输入时尽量保持焦点，不每个按键都滚动页面。

### 技术边界

建立英/西语共用学习外框：头部、中间可滚动正文、底部答题区。基于实际可见高度适配，优先读取 VisualViewport 的 height/offsetTop 与 resize/scroll 事件；在不支持时回退动态视口和普通可滚动布局。区分软键盘、浏览器地址栏变化、横竖屏和缩放，避免硬编码键盘高度。

固定操作区必须相对真正可见范围，不只是布局视口底边；安全区只计一次。仅学习路由管理页面级滚动，退出必须恢复，不能全站禁止滚动导致词库和设置不可达。滚动层保持一个明确的正文区域，不制造双层滚动陷阱。

将自动聚焦、重音字母插入和“不认识”答案聚焦纳入统一策略；可用 `preventScroll` 时避免隐式整页滚动，必要时只把目标滚入正文区。禁止每次 viewport 变化都 `window.scrollTo(0,0)`，也不通过禁止缩放解决问题。支持软键盘收起、键盘提交、快速切题与恢复会话。

参考：[MDN VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport) 说明软键盘可能缩小可见视口而不缩小布局视口，因此实际软键盘与单纯调整浏览器窗口需要分开验收。

### 界面验收

- 390×844、430×932 及约 390×440 可见高度下，顶部结束/熟练、输入与提交按钮保持可达；普通题目无需整页上下寻找操作。
- 英语四关、西语长句、错误对比、提示、不认识、跳过、特殊字母、详情展开、刷新恢复都检查；不能因收紧布局泄漏答案或改变调度。
- 768px、桌面、横屏、深浅色、文字放大、减少动画和键盘导航仍可使用，扩展内容可完整查看。
- 真机验收包括 iPhone Safari/主屏幕 PWA 和 Android Chrome 的打开/关闭键盘、地址栏变化、切题与重音输入；无真实设备时明确列为未完成，不用桌面缩窗代替手机键盘验收。
