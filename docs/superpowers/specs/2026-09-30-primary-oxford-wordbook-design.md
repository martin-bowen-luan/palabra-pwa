## 3. 方案选择

采用独立 `bookId` 与词条 ID：保留所有旧词条 ID，新增小学词条使用 `en:oxford-primary:<normalized-term>`，将英语读取与学习记录按词表限定。重合词也保持不同学习单位。

不采用同词共享进度（用户已选择独立），也不把小学伪装成第三种语言（否则会破坏英语发音、AI、拼写和显示逻辑）。`language` 仍为 `en`，`bookId` 表示具体课程。

首版词表 ID 为 `en-highschool`、`en-oxford-primary`、`es-foundation`。小学不同年级/学期只作为同一本词表的归属筛选，不额外拆成十二套进度。

## 4. 使用体验与默认规则

- 英语主页面增加文字式词表选择：高考 3500 / 小学必背单词（牛津版）。首次升级维持用户原有语言，英语默认仍选高考，不自动切换或开始新任务。
- 今日、词库、进度、设置明确显示当前词表。小学词库提供年级“全部、一至六年级”、学期“全部、上、下”筛选；组合条件作用于同一册归属，不能将不同归属交叉匹配。
- 今日页可选择小学新词的年级与学期范围，默认全部；与词库浏览筛选分开保存，浏览搜索不暗中改变学习计划。范围内新词按年级、上/下学期排序，同一册沿用源文件出现顺序；源文件不含课内单元顺序，不宣称按课文顺序。
- 年级范围只限定新词。到期复习仍覆盖小学词表所有已学词，并以文字说明，避免换年级后遗漏复习。小学词表内同词多册不重复学习或计数。
- 日目标和题型设置继续共用当前英语设置；今日完成数量、复习、统计、连续学习天数及未完成会话按词表隔离。高考当天背完十词，不会消耗小学十词的额度。
- 学习页不提供词表切换。结束/退出时先保存当前会话，再回主页面切换；各词表独立保留会话，切回可恢复题目、输入、提示、反馈和复测队列。
- 清空记录改为“清空当前词表学习记录”，确认框写明词表名；小学清空不影响高考、西语、词典内容、AI 配置或 Wordle。
- 继续使用练习纸与蓝色批注，不新增底部导航或卡片仪表盘；筛选与选择控件有键盘焦点、44px 触控区及深色样式。

以上筛选作用范围、设置共用和同词跨学期去重为本方案建议默认值，随书面方案确认。

## 5. 词典整理与内容质量

新增可重复执行的导入器，读取该 JSON，校验数量、版本、唯一词形及有效册归属。只提取词形、词性、中文义项、英中例句、发音信息、特殊变形、相关词、来源 URL、抓取时间和年级学期归属。输出轻量词库 JSON、册目录和质量报告；网页 HTML 不进入产物或运行时。

保留原始显示大小写；规范化 ID 使用 Unicode NFC、首尾去空白、统一单词间空格及小写。不将连字符、撇号或词形变体随意折叠为同一 ID。短语保留为完整学习单位，拼写提示不把空格和标点作为需要揭示的字母。

词性由明确的词性标记解析，不使用“第一个汉字之前都算词性”的规则，避免吞掉 `X光` 的 X、括号内学科标签等正文。来源 `detail_url` 正确映射为词典链接。多义项保留词性关联，不能把后一义项的词性误并入第一义项。

4 条缺失释义以小学常用义补齐并记录补充来源；疑似错义或不适龄义项列入报告并逐项处理。8 条缺失例句在开发阶段补充自然、简短的情境句和中文译文，逐条复核；允许编辑原创句，明确标记为编辑补充，不伪称来自抓取网站。不调用用户密钥或付费生成服务，也不在学习时临时生成题目。

对已有例句检查英中配对、空值、用法标题混入、残句、乱码、占位表达和目标词/正确变化形式是否出现；机器报告中的问题逐条人工复核，不能用“有字符串”代替有效例句。不无条件复制高考词表的资料，例如现有 `seaweed` 例句残缺，不能用来补齐小学内容。

短语可在自然例句中用合理变形，例如 `on one's way to` 可对应 `on my way to school`；记录匹配或编辑审核说明，不因缺少逐字子串误删有效例句。拼写答案仍为当前词条完整词形，原有忽略大小写和首尾空格规则不变；常见拼写变体只在核验后显式配置。

学习卡最多展示 3 个常用中文义项与 1 组例句，详情最多 3 组；完整源记录不等于全部显示。所有小学学习单位至少一条合格双语例句和非空中文义项，未解决缺口阻止正式构建收录，不能静默丢词后声称 1,047 条齐全。

## 6. 发音、AI 与 Wordle 边界

- 优先复用同词已存在且来源清楚的本地录音；否则沿用现有 HTTPS 在线词音播放方式，来源随词条保存。无音频时使用设备英语语音并明确提示；无可用语音时显示错误，不保证所有设备都有离线英语声音。
- 不为本次词表变更批量下载第三方音频或创建新的离线音频包；现有音频包明确标为高考词库音频包，不显示为小学完整包。词库、例句和学习记录可离线，未缓存录音不能承诺离线播放。
- 对可下载再分发音频与文本的授权不作假定。现有在线来源与本地数据保留出处；公开发布前需完成来源及使用权检查，不把抓取成功当作许可。
- 小学仍属英语，可复用用户主动启用的 AI 分析、合并与例句朗读；新词条 ID 自然隔离分析缓存，不自动扫描全表。配置和密钥不复制，已有高考缓存不删除。
- Wordle 首版继续用高考五字母词池与原有 ECDICT 验证，不随学习词表切换改变题目或游戏存档。不在本次改动扩展 Wordle 玩法。

## 7. 本地数据与兼容

当前实际数据库为 IndexedDB v6；本功能拟升级至 v7。好友小组文档中 v7 尚未实现，恢复该项目时应按当时实际版本重新分配迁移号，不能复用本功能升级号。

新增 `WordbookId` 和册归属类型。词条增加 `bookId` 与可选 `bookMemberships`（grade 1–6、semester 1/2、sourceBookId）；进度、历史会话、活动会话明确记录词表。设置增加当前英语词表和小学新词范围。

建议存储与调度入口接受明确的学习范围 `{ language, bookId }`：词库、全部进度、会话、活动会话、保存步骤、完成分组、清空记录与统计均使用同一范围。内部校验词条 ID 确属该词表；只在 UI 过滤而底层仍按语言写入不满足独立进度。

升级事务遵循：

1. 旧英语词条、进度、历史和未完成会话缺少 bookId 的，归属 `en-highschool`；旧西语归属 `es-foundation`。不更改原词条 ID、分数、日期、阶段和反馈。
2. 活动会话键转换为按词表区分的稳定键，迁移所有队列、输入、提示和选项 ID。现有 revision 乐观并发校验继续生效，并增加范围一致性校验。
3. 词库版本与元数据按词表独立管理。旧语言元数据迁移为对应旧词表记录，小学首次导入 revision 1；不得把新增小学词库作为替换全部英语词库。
4. 小学词库和元数据在单个事务中初始化/更新；失败时保留旧词库与用户记录。初始化串行化，多标签页升级主动关闭旧连接。
5. 学习与会话结束的事务写入仅影响目标词表；清空记录也按词表执行。西语每日词形记录仍使用原有语义。

AppState 暴露当前词表词库、进度、历史和活动会话。切换异步加载必须以请求代次防止旧结果回写；只有完整载入并保存选择成功才显示新词表，失败保持原状态并可重试。刷新默认恢复已选择的词表和其未完成会话。

词条详情与相关词链接只在当前词表解析，不因词形重合跳到高考进度。旧高考词条链接继续兼容；跨词表链接应明确词表参数并在学习中提示先退出，不静默切换当前学习状态。
