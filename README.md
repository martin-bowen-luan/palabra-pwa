# palabra

一款面向中文学习者的离线背词 PWA。可切换西班牙语 A1 词库（300 词）和英语“高考 3500”词库（实际 3464 词），两种语言的学习记录互相独立。

每日任务按最多 10 个词一组进行；若设置为 15 或 20 个新词，完成一组后点击“开始下一组”。忘记、模糊或答错的词会立即重做，并在穿插几个词后再次出现，直到答对。学习中可将词标为熟练，之后不再安排复习。词库的“已背”页可查看当前语言学过的词。

英语首页提供独立的“学习”和“复习”入口。每组依次完成四关：选择释义、例句辅助回忆、无提示回忆、集中拼写。后两种回忆需要揭示答案后核对；拼写错误会逐字显示漏写、多写或替换的字母，也可选择跳过。跳过不计为熟练，会安排约 10 分钟后的优先复习。未完成旧版会话继续使用原流程，完成后新建会话采用四关流程。

英语释义题优先使用形近词，排除当天学过的干扰词；自动发音失败时可点击扬声器重播。词库不足四个有效选项时，第一关采用主动回忆并核对答案。词条详情可切换派生词、词根、近义词与特殊变形。

英语复习参考间隔为 10 分钟、1、2、4、7、15、30 天：完成一组只更新一次记忆阶段，答错或跳过后回到短间隔，后续成功复习逐渐延长。到期词按已过去时间与上次间隔的比值排序，跳过词增加 0.25 的优先权重，因此长期逾期词仍能排在前面。这是参考遗忘规律的产品策略，非统一的科学最优时间表；参见 [间隔重复研究综述](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2017.00962/full)。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/today`。

## 验证与构建

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

生产构建位于 `dist/`。首次在线打开后，应用壳、词库和字体会由 Service Worker 缓存，可继续离线学习。

## 数据说明

词库、学习进度、设置和打卡记录保存在浏览器 IndexedDB 中。学习记录不会上传；可选 AI 模式仅发送正在查看的词汇资料，详见下节。设置页可按当前语言清空学习记录，不删除词库或 AI 配置、分析缓存。手机与电脑的本地记录不会自动同步。

词根与派生关系由 `node scripts/import-english-relations.mjs` 从 Wiktionary 的明确英文构词模板提取，保存逐条版本来源；使用 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 并署名 Wiktionary contributors。仅提取有可解释词基/词缀的记录；没有可靠资料的词显示空状态。应用启动时统一将这些字段导入 IndexedDB；使用过程中无须实时访问词典。

## 可选 AI 模式（默认关闭，仅英语）

在“设置 → AI 词汇分析”阅读数据、费用和密钥说明后启用。选择 DeepSeek、Qwen（北京/新加坡预设，可手动替换地域地址）或自定义兼容服务，填写 HTTPS Base URL、模型名和 API 密钥，再设置至少 8 字符的本地加密密码并确认目标地址。填写基础地址，不要附加 `/chat/completions`。服务必须支持浏览器跨域请求；应用不会使用公共代理。参考 [DeepSeek API 文档](https://api-docs.deepseek.com/) 与 [Qwen 地域地址说明](https://www.alibabacloud.com/help/en/model-studio/base-url)。

密钥使用 PBKDF2-SHA-256（600000 次）和 AES-256-GCM 加密存入 IndexedDB v4，密文绑定服务地址。密码与解锁后的密钥不持久保存，刷新后需解锁；锁定、关闭 AI 或其他标签页修改配置会使内存密钥失效。修改服务地址必须重新输入密钥、确认新目标。忘记密码可清除模型配置后重设，不影响学习记录。加密不能防御恶意网页脚本、已被入侵的浏览器或解锁期间的设备访问。

只在词库详情、已揭示答案中分析当前词，发送词形、义项、例句与已有词汇关系，不发送进度。分析异步进行，最多一个请求、超时 60 秒，无自动循环重试；“测试连接”和“重新分析”可能产生 API 费用。按词、地址、模型、输入摘要和提示词版本缓存（包含有效空结果），离线或密钥锁定时仍能查看已有分析。清除某词分析后，本次查看不会立即重新生成。

词典资料原样保留，AI 派生词、词根/词缀/记忆联想、近义词以“AI 补充”或“AI 不同分析，未核实”分层显示，并标注模型和时间。结果不改变答案、学习计划或复习调度。模型输出可能错误，不能替代词典核验。

AI 模式下，已显示的英文例句可点击朗读、停止或重播；使用系统英语语音，不调用文本模型、不需要解锁 API 密钥。优先本地美式英语、其次本地其他英语，联网时可使用系统远程英语语音；离线需预先安装本地英语语音。句子和单词发音互斥，系统语音不生成可供本应用下载缓存的音频。无可用语音时显示错误，不假装已播放；参见 [MDN localService](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)。

开发自动化测试使用模拟 API 和系统语音事件。真实 DeepSeek/Qwen 调用需要使用者在设置中提供有效配置；真实手机语音、系统权限和跨域限制需在目标设备另行验收。

选择 DeepSeek 服务商时（包括 `deepseek-flash`），应用显式关闭思考模式并请求 JSON 输出，保留 4096 token 上限。Qwen 和自定义服务不附加这些 DeepSeek 参数。JSON 模式仍可能截断，应用继续拒绝不完整结果、保留旧缓存，不自动重试产生额外费用；可手动重新分析。已有有效缓存继续复用。
