# palabra

一款面向中文学习者的离线背词 PWA。可切换西班牙语 A1 词库（300 词）和英语“高考 3500”词库（实际 3464 词），两种语言的学习记录互相独立。

每日任务按最多 10 个词一组进行；若设置为 15 或 20 个新词，完成一组后点击“开始下一组”。忘记、模糊或答错的词会立即重做，并在穿插几个词后再次出现，直到答对。学习中可将词标为熟练，之后不再安排复习。词库的“已背”页可查看当前语言学过的词。

英语学习卡提供近义词、特殊变形、音标和发音。英语释义选择题优先使用形近词作为干扰项，排除当天学过的词；进入题目时尝试自动播放，扬声器可重播。浏览器阻止自动播放时，仍可手动点击扬声器。词库不足四个有效选项时，该题改为拼写。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/today`。

## 验证与构建

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

生产构建位于 `dist/`。首次在线打开后，应用壳、词库和字体会由 Service Worker 缓存，可继续离线学习。

## 数据说明

词库、学习进度、设置和打卡记录保存在浏览器 IndexedDB 中，不会上传到服务器。设置页可按当前语言清空学习记录，不删除词库。手机与电脑的本地记录不会自动同步。
